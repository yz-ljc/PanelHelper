# 架构与开发约定

## 目录

```text
src/           Vue 界面、预览组件和样式
shared/        配置文件解析与服务端输入校验
server/        本地 HTTP 服务、会话和 QQ API 适配
test/          Node.js 测试与模拟 QQ 接口
scripts/       分发包构建脚本
docs/          使用与开发文档
dist/          前端构建产物（忽略）
release/       ZIP 分发包和校验文件（忽略）
```

## 请求流程

浏览器通过同源 `/api` 路径访问本地服务。本地服务获取并缓存 QQ 访问令牌，以 `QQBot` 鉴权请求官方菜单和面板接口。浏览器仅接收机器人资料、会话校验值和配置数据。

AppSecret 用于 `https://api.bot.qq.com/app/getAppAccessToken`。业务接口固定为 `https://api.sgroup.qq.com`，不接受用户指定的 API 地址。

`server/qq-client.mjs` 负责官方接口字段与前端数据模型的转换。`shared/menu-panel-transfer.mjs` 保留 `atribot-menu-panel` 格式标识，用于与原项目导出文件兼容；修改格式需要显式版本迁移。

会话、令牌与写入队列均为进程内状态，不存在数据库或凭据配置文件。读取请求遇到令牌失效时允许刷新后重试一次；写入请求不自动重放，避免不确定状态下重复提交。创建全局面板按机器人和场景串行化，并先遍历远程列表检查现有面板。该保护只覆盖当前本地服务进程，不能替代远程平台的并发控制。

## 验证

`npm test` 使用 Node.js 自带测试框架和注入的模拟 QQ 接口，覆盖会话、来源限制、CSRF、菜单字段转换、四场景面板管理、关联对象、分页与创建冲突。测试不需要真实凭据，也不会修改远程配置。

持续集成在 Windows 与 Linux、Node.js 22 与 24 环境执行依赖安装、测试和打包。新增接口应同时提供失败路径测试；涉及 UI 的调整应检查桌面和窄屏布局。

## 分发

`npm run release` 先执行前端构建，再按明确的文件白名单生成 ZIP 及 SHA-256 校验文件。压缩包使用标准 ZIP 存储格式，由 Node.js 内置模块构建，不依赖系统压缩命令。分发包不包含 Node.js 本身。

独立仓库应在本目录进行版本管理。宿主仓库通过自身 `.git/info/exclude` 忽略该目录，此设置只对本地仓库有效，不写入宿主项目的公共 `.gitignore`。

## 贡献约定

使用 UTF-8、LF 换行和两空格缩进；Windows 启动脚本使用 CRLF。注释仅解释必要的约束或决策，避免复述代码。不得提交真实 AppSecret、访问令牌、含凭据的截图或导出的业务配置。修改依赖后同步更新锁文件及适用的第三方声明。
