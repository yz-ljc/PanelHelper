# 使用说明

## 登录与机器人信息

登录需要机器人 AppID 和 AppSecret，不使用 QQ 账号密码。菜单与面板请求统一发送至 QQ 正式接口。登录成功后，侧栏展示 QQ 接口返回的机器人信息；需要切换机器人时，先退出登录。

浏览器刷新可恢复仍有效的会话。工具不提供记住 AppSecret 的功能，也不会将其写入配置文件或浏览器本地存储。

## 自定义菜单

自定义菜单用于单聊场景，最多包含 10 个一级菜单。支持以下类型：

| 类型 | 配置内容 |
| --- | --- |
| 发送消息 | 按钮名称与发送内容 |
| 链接跳转 | 按钮名称与 HTTPS 链接 |
| 开关 | 按钮名称、唯一开关标识与默认状态 |
| 折叠子菜单 | 按钮名称及最多 5 个子项；子项支持消息或链接 |

一级名称最多 5 个汉字或 10 个英文字符，子项名称最多 7 个汉字或 14 个英文字符。编辑器按字符权重限制长度。拖动菜单项左侧手柄可调整顺序。

手机预览用于检查内容与布局，实际展示以 QQ 客户端为准。编辑后选择“保存菜单”提交；“重新加载”会以远程配置替换当前编辑内容。

## 指令面板

面板支持私聊、群聊、频道文字子频道和频道私信。新建时选择场景、适用范围和面板项目；每个面板最多 20 项，项目支持指令和 HTTPS 链接。

全局面板作用于所选场景。工具在创建前检查是否已有全局面板，并要求通过编辑已有面板进行修改。指定对象面板仅支持私聊和群聊，分别使用用户 OpenID 或群 OpenID；不能直接使用 QQ 号码或群号码替代。

通过“管理关联”添加或移除适用对象，每次操作最多 20 个 ID。删除面板需要确认。旧版 `mp_` 前缀面板无法通过本工具删除。

## 配置文件

菜单和面板可分别导出为 JSON，再通过“导入单项”读取。文件包含菜单、指令和关联对象等配置，不包含 AppSecret 或访问令牌。分享文件前应检查其中的业务内容和 OpenID。

顶部“导入单项”会先展示确认信息，确认后直接提交菜单，或创建面板、更新所选场景的已有全局面板。面板编辑窗口内的导入仅替换当前编辑内容，需要保存后才会生效。导入不是跨多个接口的原子事务；失败时请刷新列表确认已生效的部分。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 无法启动 | 检查 Node.js 版本、解压是否完整、端口是否被占用 |
| 无法连接 QQ 官方接口 | 检查本机网络和 QQ 接口可用性 |
| 登录失败 | 核对 AppID 和 AppSecret，检查机器人是否具备访问权限 |
| QQ 接口返回权限或频率错误 | 根据返回信息检查平台配置，或稍后重试 |
| 保存请求超时 | 先重新加载确认远程状态，再决定是否重试 |
| 会话已失效 | 重新登录；进程重启会使此前会话失效 |

菜单和面板最终受 QQ 官方接口及机器人权限约束。本地校验通过不代表远程平台一定接受配置。
